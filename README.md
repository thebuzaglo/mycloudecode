# 🍽️ התפריט השבועי הדיגיטלי של שלומי

תפריט שבועי מבוסס על תוכנית התזונה של דור אקשטיין, בנוי מ:

- **אוכל מוכן** מ‑[PROMEAL](https://promealfood.com/) — ימים ראשון–חמישי (חימום 3 דק' במיקרו)
- **השלמות** מ‑[Wolt Market פלורנטין](https://wolt.com/he/isr/tel-aviv/venue/wolt-market-florentine) — שישי–שבת, ירקות, גבינות וביניים

## מה יש בפנים

- תפריט יומי ראשון–שבת עם תמונות של כל מנה ולינק לחיץ למנה באתר
- סל הזמנה שבועי מרוכז מ‑PROMEAL (13 פריטים, ₪763)
- רשימת קניות מ‑Wolt Market עם לינק חיפוש לחיץ לכל מוצר
- תזכורת לחוקי התפריט (מותר / אסור / חופשי)
